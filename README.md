**The World Today — Sunday 22 November 2026, the whole day on one page.** A program that draws one 1024×1024 front page summing up the world news of Sunday 22 November 2026: **36 dated stories organised by region** — the COP31 climate talks collapse in Antalya as the lead, then Europe, the Middle East, Asia-Pacific, the Americas, Africa and Sport & Science panels, a markets strip (S&P 500 −3.7%, NASDAQ −5.3%, Nikkei −5.1% as stocks slide into correction) and an In Brief band. Drawn entirely from code with a hand-built 5×7 bitmap font and a tiny PNG encoder. No image assets, no network, deterministic byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
